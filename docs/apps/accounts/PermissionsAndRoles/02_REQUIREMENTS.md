# Permissions & Roles - Requirements

**Feature:** Role-Based Access Control  
**Status:** Phase 1 ✅, Phase 2 Planned  
**Last Updated:** October 22, 2025

---

## 📋 FUNCTIONAL REQUIREMENTS

### FR1: Department-Based Permissions (IMPLEMENTED)
- FR1.1: System SHALL support department assignment
- FR1.2: System SHALL filter data by user department
- FR1.3: System SHALL restrict access to department resources

### FR2: User Groups (IMPLEMENTED)
- FR2.1: System SHALL support UserGroups model
- FR2.2: System SHALL allow group-based permissions
- FR2.3: System SHALL support many-to-many user-group relationships

### FR3: Staff/Admin Flags (IMPLEMENTED)
- FR3.1: System SHALL differentiate staff vs non-staff
- FR3.2: System SHALL provide is_admin flag for super-admin
- FR3.3: System SHALL use flags for permission checks

### FR4: Custom Roles (Phase 2 - PLANNED)
- FR4.1: System SHALL allow creation of custom roles
- FR4.2: System SHALL support role-permission mapping
- FR4.3: System SHALL allow role assignment to users
- FR4.4: System SHALL support role hierarchies
