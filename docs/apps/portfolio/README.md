## Overview

Unified presentation system for showcasing CODA projects to different audiences (investors, technical teams, recruiters) with branding options.

## Key Features
- Multiple presentation modes
- Project-specific presentations
- CODA branding vs white-label
- Portfolio hub dashboard

## Production URLs
- Portfolio Hub: `/portfolio/`
- Project Presentations: `/portfolio/{project}/{mode}/`
- Interview Presentations: `/portfolio/{project}/technical/` or `/recruiter/`
