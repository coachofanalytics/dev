## 🎯 Quick Start

### For New Developers:
1. **Read:** [CURSOR_AI_GUIDE.md](CURSOR_AI_GUIDE.md) (complete development guide)
2. **Setup:** Run `setup_development_environment.py`
3. **Explore:** Navigate to `docs/apps/finance/` for feature docs
4. **Test:** Run `./tests/run_tests.sh`

### For Cursor AI:
1. **Always read:** [CURSOR_AI_GUIDE.md](CURSOR_AI_GUIDE.md) first
2. **Then read:** Feature-specific docs in `docs/apps/finance/[Feature]/`
3. **Follow:** Development workflow in the guide
4. **Remember:** Never deploy to production without user permission!
