This folder is for Healthcare Information page images.

You can add images here and the page will automatically use them as fallbacks if you haven't uploaded images via the admin.

The template will look for either the recommended short names OR the filenames you provided. Save your files using one of these sets of names (extensions allowed: .jpg, .jpeg, .png, .webp, .gif):

Recommended (short names):
- hero.jpg or hero.png — Hero image, recommended size: 1600x800 or 1200x600
- services.jpg or services.png — Image for Services block, recommended size: 1200x800
- insurance.jpg or insurance.png — Image for Insurance block, recommended size: 1200x800

Alternative (your filenames):
- healthcarehero.png  (will be used as hero)
- healthcareservices.png  (will be used as services)
- insuranceoptions.png  (will be used as insurance)

Place files in this folder and then refresh the page. If you prefer to manage images via Django admin (media uploads), use the HealthcareImage model in admin instead.
