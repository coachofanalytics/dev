ℹ️ How to Use This Dashboard
📌 Manual Categories (BOG, Elite, Lead, Support, Analysts):
  • Click "View & Manage" to see members
  • Add/remove members manually
  • Set priority (higher = displayed first)
  • Points are calculated but don't affect categorization
📊 Points-Based Categories (Trainees):
  • Members auto-categorize by points
  • Senior Trainee: 5,000-6,000 points
  • Junior Trainee: 4,000-5,000 points
  • Elementary: < 4,000 points
  • At 6,000+ points: Flagged for manual promotion
🎯 Promoting Members:
  • System auto-flags members with 6,000+ points
  • Review candidates in alert above
  • Click "Promote" or use Django Admin bulk action
  • Add promotion notes for tracking
