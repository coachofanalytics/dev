ℹ️ How to Use This Dashboard
🔄 Hybrid Assignment System:

ALL categories support BOTH modes:

  • 📌 Manual (Pinned): Admin assigns - member stays regardless of points
  • 📊 Auto (Points): System assigns - member may move on recalculation
📊 Point Thresholds (for Auto-Assignment):
  • Senior Trainee: 5,000-6,000 points
  • Junior Trainee: 4,000-5,000 points
  • Elementary: < 4,000 points
  • 6,000+ points: Flagged for promotion review
🎯 How to Manage:
  • Add Member: Click "View & Manage" → Click "Add to [Category]" → Auto-assigned by default
  • Pin Member: Use Django Admin → Mark "is_manually_assigned" = True
  • Recalculate: Click "Recalculate All Points" → Only affects auto-assigned members
  • Remove: Click trash icon → Removes from category
💡 Best Practices:
  • Leadership (BOG, Elite): Always manually pin
  • Core Team (Lead, Support, Analysts): Manually pin established members
  • Trainees: Let system auto-assign, manually pin when ready
