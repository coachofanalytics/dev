## DATA QUALITY IMPROVEMENTS

### Issues Found:

1. **Case Variations:**
   - "Labour Cost" vs "Labour cost" vs "LABOUR COST"
   - "Material Cost" vs "Material cost"
   - "HR Cost" vs "HR cost" vs "HRM Cost" vs "HRM cost"

2. **Mixed Categories:**
   - Salaries contains food/supply items
   - "Other" used 46 times across categories (31% of items)

3. **Location Mixing:**
   - "Matunda" and "Makutano" mixed into receiver names
   - Should be in location field

4. **Vague Type Names:**
   - "Other" (46 occurrences)
   - "Miscellaneous" (9 occurrences)
   - Need more specific descriptions

### Recommendations:

1. **Standardization:**
   - Create dropdown for common items (prevents variations)
   - Enforce case consistency
   - Reduce "Other" usage to <5%

2. **Category Cleanup:**
   - Split "Salaries and Wages" → separate "Employee Compensation" from "Operations"
   - Split "Operational Expenses" → separate "Food & Supplies" category
   - Merge dormant categories or populate with data

3. **Smart Form Enhancement:**
   - Add most common items to auto-complete
   - Suggest items based on category + subcategory
   - Warn when using "Other" (ask for specifics)

4. **Location Field:**
   - Add location dropdown: Matunda, Makutano, Nairobi HQ, Remote
   - Extract location from existing receiver names
   - Prevent future mixing
